## Introduction

'jhonny-the-stalker' is a simple project written in Python with a command-line interface, focused on OSINT and verifying credentials and users on the web. It is easy to install and run, all you need is just the external libs in 'requirements.txt' and python installed in your machine.

## Installation

```bash
git clone https://github.com/mn7god/jhonny-the-stalker
cd jhonny-the-stalker
pip install requirements.txt
python3 jts.py
```
After running the python script type 'help' on the console to show available commands.
